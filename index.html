准备工作

下载安装后，完成两步准备即可开工：装好处理引擎、激活授权。都只需做一次。

处理引擎配置

首选：设置里一键搞定——首次打开 FFlow，点顶栏齿轮进设置 → 版本信息：入口就在 ffmpeg 版本行上（下图红框处）：在线点「安装」（约 70 MB，联网仅此一次，进度可见）；离线机器点「导入」，选择从官网下载的引擎 zip——免解压、免输路径（官网引擎包按系统分 Windows / Linux 两份，应用内在线安装会自动匹配当前系统）。

也可以：直接放在程序旁——解压引擎包，把 ffmpeg / ffprobe 两个文件（Windows 下带 .exe 后缀）与 FFlow 放同一文件夹（bin 子文件夹也行），启动自动识别。

方式 A：与 FFlow.exe 同一文件夹
FFFlow.exe主程序（lite 包解压）
fffmpeg.exe引擎（引擎包解压取出）
fffprobe.exe引擎（引擎包解压取出）
方式 B：放进 bin 子文件夹
fbin\ffmpeg.exe在 FFlow.exe 旁新建 bin 文件夹放入两个引擎文件
fbin\ffprobe.exeFFlow.exe 仍在 bin 的上一级

两种摆法启动都会自动识别，无需任何设置。

如何激活

不激活也能先试用。需要正式使用时，三步完成：

  1. 复制设备指纹——打开 FFlow，进入 设置 → 版本信息，复制设备指纹（下图红框处）。
  2. 发给开发者——注明想要的版本（简易 / 专业）与使用时长，等待收到激活令牌。
  3. 粘贴激活——回到 版本信息 页，把令牌粘贴进去，完成激活。

简易版想升级专业版？重新激活一张专业版令牌即可，不用重装。

猜你想问

使用时需要联网吗？

处理视频全程在本机完成，不需要联网。处理引擎联网可一键安装，不联网也能离线导入引擎包。「AI 一句话处理」需要联网使用。

我的视频会被上传吗？

不会。所有处理都在本机完成，软件不收集、不上传你的视频。

杀毒软件提示有风险？

程序做了代码加固，个别杀毒软件可能误报。确认下载来源为本站后，添加信任即可正常使用。

Linux 版打不开怎么办？

多半是安装包与系统版本不匹配——直接换另一份安装包试试（两份总有一份能跑）；仍不行时在终端运行 ./FFlow，按提示补装缺失组件即可。

怎么升级到新版本？

下载新版本解压运行即可；Linux 版运行一次新版就完成升级。旧版本可删除，设置 → 版本信息 里可查看当前版本号。

支持哪些系统？

Windows 10 / 11（64 位）与 Linux 主流发行版（64 位，按系统新旧选择安装包）。
