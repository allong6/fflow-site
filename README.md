# FFlow 官网

**FFlow** 是一款本地视频工具箱（Windows / Linux）：把视频拖进来，即可完成
格式转换、体积压缩、画面处理、画质增强、GIF 截图与多视频合成——全程在
本机运行，不上传、不限速。

- 🌐 官网：<https://allong6.github.io/fflow-site/>
- ⬇️ 下载：官网[下载页](https://allong6.github.io/fflow-site/#download)，或本仓库 [Releases](https://github.com/allong6/fflow-site/releases)
- 💬 反馈与需求：[提交 issue](https://github.com/allong6/fflow-site/issues/new/choose)（功能需求 / 问题反馈）

## 这个仓库是什么

FFlow 官网的静态页面与安装包分发通道。每次发版，版本更新说明会
自动同步到官网的「更新说明」区，历史版本均可下载。
